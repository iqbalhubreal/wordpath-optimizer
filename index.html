Features

Everything between a raw list and a finished puzzle set

A focused toolkit for crossword makers: arrange, review, write clues, and export, all in one place.

Letter-linked chains

Each word connects to the next through a shared letter, avoiding neighbouring-letter overlaps so grids stay fillable.

Multi-pass optimization

Pick Quick, Balanced or Deep. WordPath tries many arrangements and keeps the one that leaves the fewest words unused.

Gemini titles & clues

Generate a fitting title and a clear, crossword-style clue for every word on a chain card with one click.

Batches

Work through several lists side by side. Each batch keeps its own words and results until you close the tab.

Copy & export

Copy a single card, copy the whole report, or download a clean .txt file ready for your workflow.

Private by design

Privacy & data

Your list stays in your browser

There is no WordPath server and no account. Chain-building happens on your device. Your Gemini API key is saved in this browser only when you choose to save it.

  • 1

    Optimization is local

    Your full word list is processed in this tab and never uploaded.

  • 2

    Gemini receives only what you send

    When you generate clues, only the words on that one chain card go to Google, directly from your browser.

  • 3

    Your API key stays in this browser

    Choose “Save key in this browser” to keep it in this browser's local storage. It is sent directly to Google's Gemini API when you request AI output. Use this only on a trusted device.

FAQ

Frequently asked questions

Can't find your answer? The studio itself has inline help for every setting.

Does WordPath send my entire word list to Gemini?

No. The optimizer runs locally in your browser. Only the words on a specific chain card are sent to Google, and only when you choose to generate that card's title and clues.

Where is my API key stored?

Your key is not sent to a WordPath server. Unless you choose “Save key in this browser,” it stays only in the input field while the page is open. A saved key is kept in this site's browser local storage until you select “Remove saved key” or clear this site's browser data. Browser storage is not encrypted, so never save a key on a shared or public device.

How do I save or remove my API key?

Paste the key and select “Save key in this browser” to keep it for future visits on this browser. Select “Remove saved key” to delete the stored copy and clear the input field. Only save keys on a device and browser profile you trust.

Do I need a Gemini API key to use WordPath?

No. Building and exporting chains works without one. A key is only needed for AI-written titles and clues. You can get one from Google AI Studio.

Why might Gemini fail to connect?

Check your internet connection, the key's Gemini API access, selected-model availability, and your Google AI Studio quota. Standard API keys must have appropriate API restrictions; Google rejects unrestricted standard keys. Try another available model and select “Test connection” again.

Are the generated chains guaranteed to be optimal?

No. WordPath tries many arrangements and keeps the best one found. A deeper run can find a better arrangement, but results can vary from run to run.

What happens to words that don't fit a chain?

They appear as unused words in the results so you can review them, add more words to the batch, or run the optimizer again.

Is my work saved if I close the tab?

Word lists and results live in the open tab only, so copy your cards or export the .txt report before leaving. If you separately saved your API key, it remains in this browser until you remove it or clear this site's browser data.

How much does it cost?

WordPath Studio is free to use. If you generate clues, requests are made with your own Gemini key and are subject to Google's pricing and quotas.
